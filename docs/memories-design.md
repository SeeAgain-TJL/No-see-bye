# 记忆模块 V1

门户是功能容器，记忆是第一个模块。先采用单个 Next.js 应用、SQLite 与本地私有文件目录，适合单台 ECS 上的小规模多人使用。

## 体验与路由

- 门户：模块入口、最近记录和真实空状态，不灌入虚构日记。
- 账号：用户名/邮箱和密码，每个人独立的记忆与配额。
- 记录：文字、图片、视频可单独或混合；发生时间与创建时间分开，可补记日期、地点、心情和标签。
- 浏览：月份分组、卡片/时间线、关键词/类型/月份/收藏筛选、稳定游标分页。
- 编辑：拖放多选、预览、调序、进度、取消和失败重试；成功的附件不重复上传。
- 草稿：按账号和记录分开保存本机文字；不保存二进制附件，不跨设备同步。
- 权限：默认私密。公开后任何访客可看正文与原媒体，每次媒体请求均鉴权，包括视频 Range。
- 整理：收藏、编辑冲突检测、软删除和恢复。不自动到期；支持用户确认后清空回收站，永久删除当前用户确认范围内的记录及其附件。

路由：/ 门户；/login 和 /register；/memories；/memories/new；/memories/[id]；/memories/[id]/edit；/memories/trash。公开浏览使用 ?scope=public。

视觉采用纸白、松绿和暖棕，偏相册与手札阅读体验。手机使用单列和底部导航，媒体使用原生对话框，支持键盘及减少动态效果偏好。

## 数据和模块边界

src/core 管理认证、数据库、存储和请求校验；src/modules/memories 管理记录服务与界面；src/components 是共享门户界面。

保留早期 Entry 表并增量增加字段，不删除旧记录。Asset 保存所有者、驱动、文件引用、大小与状态；EntryAsset 保存附件顺序，一个附件仅属于一条记录。标签暂存有界 JSON 数组，后续拆独立标签与全文搜索。旧 TOS media 引用原样保留，没有自动下载迁移。

文件在 public/ 外。上传流式写盘，检查声明与实际大小、格式白名单及基础文件头，按用户预留配额以防并行超额。不把文件头识别等同于完整媒体解码或病毒扫描。
