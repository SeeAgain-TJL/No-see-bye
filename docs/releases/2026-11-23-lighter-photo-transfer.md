# 登录区微调与照片传输优化

以上一线上版本 PR #29（`6cc4d06`）为基线。

- 900 至 1080 像素高的桌面窗口中，登录注册组合上移约 10 至 21 像素。手机端按屏幕尺寸加载轻量插画，草地版本从约 165 KB 降至约 49 KB。
- 新生成的照片预览最长边为 1024 像素，已有预览沿用系统中已存的版本。高清查看规格为 1920 像素，并在打开对应照片时加载。编辑已有记录时，附件列表使用缩略图。支持报告网络状态的浏览器可以按网速选用轻量首页封面视频，省流量模式使用静态封面。
- 选择大 JPG 时可勾选「加速上传」，设备会生成最长边为 3072 像素的压缩版，体积至少减少 20% 时上传该版本。默认上传原始文件。

生产构建、Lint、类型检查、459 项 API 集成检查及浏览器登录与首页回归通过。浏览器夹具测试中，带方向标记的 JPG 从约 8.6 MB 降至约 4.2 MB，显示方向正确。原图模式下核对了请求体与选中的文件一致。压缩收益随照片内容和设备而变，网速分档依赖浏览器提供的数据。部署状态以合并提交对应的 GitHub Actions `Deploy production` 为准。
