# 五套景观与三维站点观测

本次发布以线上 PR #16（`17b8bcd`）为基线。一个发布分支同时包含主题、登录和管理台改动。

## 相对上一版

- 访客首页采用森林、冰山、草地、裂谷、海洋五套配色。每套选用一张 2880 × 1512 的实拍照片，另有移动端图和主题菜单缩略图。首屏标题上移，随主题切换电影语录。可以直接拖动镜头或打开全幅照片查看摄影署名。
- 首页照片墙保留原图比例，将照片色彩柔化后延伸至留边。竖图、横图和正文链接可以各自完整查看。
- 登录与注册沿用上一版 43∶57 双栏与胶囊切换。五幅插画重绘成哑光水粉质感，把光源和材质落在木窗、冰壁、草地、峡谷石桥及海底玻璃上。萤火、折光、飞信、灯焰和水下光流按各场景的位置与方向运动，支持指针、触摸和重播。裂谷的灯桥从《寻梦环游记》的纪念与回忆主题取意。
- 管理台加入可拖动、缩放和复位的 WebGL 粒子场，并能切换成近 30 天活动图。点选一天即可在新增趋势中查看注册用户和日常作者。数据每 15 秒刷新，动画和自动刷新分别控制。
- 旧主题偏好会自动映射到新主题。全页动效适配五套场景，并遵循系统的减少动态效果设置。

摄影出处见 [摄影与插画来源](../../public/visuals/CREDITS.md)。交互参考了 [MotionSites 光标跟踪](https://www.motionsites.ai/lesson/cursor-tracking-website-with-motionsites) 和 [MotionSites 三维镜头](https://www.motionsites.ai/lesson/astra-6-build-3d-websites-for-beginners)。

## 验收与发布

- 本地 Chrome 检查了桌面和 390–400 px 移动视口下的访客首页及照片墙。登录和注册在 320、390、1440 px 验收了排版，逐套验证五个主题的播放与重播。窄屏全页动效开关放在表单下方，播放时取景框保持固定。管理台用隔离测试账号验证了 1440 px 和 390 px 布局、拖动缩放、日期双向联动及明细定位。
- 构建、TypeScript、ESLint 和照片布局检查通过。412 项集成接口检查和 90 项管理权限、账号安全与生命周期接口检查通过。
- 管理台粒子视图需要浏览器支持 WebGL。禁用 WebGL 时仍可选择日期并查看新增明细。MotionSites 用作交互参考，完成度按可操作行为和视口验收记录。
- 生产发布由 `master` 合并触发。此版本的生产状态以相应 GitHub Actions 运行结果为准。
