# 缩小日常照片与完善发现日常互动

以上一线上版本 PR #26（`02cec42`）为基线。

- 两个日常页面缩小照片卡片和时间线相框。宽屏卡片可排四列，主页「近来拾光」的整组照片缩至原栏宽的 92%。保留原图比例、同图虚化和点击预览。
- 时光相册每张静止停留时间从 3 秒缩为 2 秒，移除下沿进度线。自动播放仍受图片加载、过渡时间和系统减少动态效果设置影响。
- 我的日常用单个更多按钮打开收藏、编辑和移到回收站，保留删除确认以及独立的回收站操作。
- 发现日常的卡片与详情使用公开互动入口。登录后可评论、点赞、收藏，并可筛选「只看我的收藏」。互动数据独立于作者自己的收藏标记，只有公开且未删除的日常可互动。评论公开显示，点赞状态与收藏归当前账号。
- 登录注册扩大表单和插画容器，保留圆角分段切换与独立的确认密码行。切换时账号、密码和插画坐标保持稳定。

生产构建、lint、类型和布局检查通过。隔离数据库通过 459 项 API 检查，并验证旧库升级、私密或已删除记录的访问、账号间收藏隔离及重复点赞。Chromium 回归覆盖 320 至 1920 像素宽度，验证卡片比例、触摸和键盘操作、公开详情、播放速度，以及六种账号页面尺寸。

部署通过 systemd 启动前的 `scripts/init-db.mjs` 增量创建互动表。发布状态以合并提交对应的 GitHub Actions `Deploy production` 为准。
