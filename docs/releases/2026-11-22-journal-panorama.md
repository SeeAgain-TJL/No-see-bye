# 日常全宽动态封面、照片比例与注册确认行

基线：正式站 PR #25（`f92e748`）。只改账号表单和两处日常页面的展示，不改登录 API、权限、数据或用户照片。

- 确认密码独占完整一行，显隐开关放进密码输入框。保留静态插画和圆角切换；登录模式不留空输入行。标题、用户名、密码不随切换移位，提交区随新增字段向下排。
- 我的日常和发现日常共用横幅，使用与主页相同的主题影片。宽屏边缘以同景静帧柔化补足；紧凑屏直接铺满。标题和原有操作置于画面内，可点背景看完整封面。减少动态效果时不加载视频。
- 时间线根据素材比例限制卡片宽度，避免竖图落在过宽的空条里；照片墙改为随内容宽度排列的等高相框。两者使用同图背景、清晰完整前景；原有网格卡片及其操作保留。未更改原图文件。

验证：生产构建、lint、类型检查、布局测试；生产构建在本地浏览器以 320–1920px 五档检查两个日常页面的三种视图、真实播放、减少动态效果、月导航与预览关闭；另外验证六种账号视口、独立确认行和稳定的公共字段。照片及已登录个人页使用本地测试数据，正式站仅做只读验收。

发布状态以本 PR 合并 SHA 的 Linux deployment bundle 与 Deploy production 结果为准。实际播放仍取决于设备的自动播放及减少动态效果设置。
