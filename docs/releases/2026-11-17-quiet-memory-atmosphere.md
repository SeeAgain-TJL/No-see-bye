# 2026-11-17 回影卡片与舒缓翻阅

发布分支：`feat/quiet-memory-atmosphere`。以此前线上 `2ecedd3`（PR #10）为基线，本轮实现、验收修正和发布说明均提交到同一个分支。

## 相对上一版

- 保留桌面 400px、手机 246px 的统一卡片规格，在桌面照片两侧及下半部加入同一预览图的低饱和回影，并以主题压印收住空白。真实文字区域降低回影强度，不补写缺失的标题或正文。有视频封面时可复用封面，未生成封面则只保留压印；不加载视频原文件充当装饰。手机隐藏这些装饰，保持紧凑。
- 全局风景撤掉折纸带、机械快门和几何仪表，改为边缘的自然连续运动：纸白细枝轻摆与风弧、海盐流动细线与低位潮纹、麦芽慢速走片与稀疏颗粒、墨林自然弧迹与低亮星点。中心照片和表单区域通过遮罩留空，手机进一步收窄可见边缘；保留全局开关、跨页状态、后台暂停和减少动态支持。
- 登录/注册左右比例从约 57.5:42.5 调整为桌面 44:56、中屏 43:57。左侧标题和光学对象同步缩小，账号表单成为更明确的操作主体，手机仍采用上下布局。
- 首页主相册从每秒一次切换改为每张稳定后停留 4 秒，再以约 1.1 秒的缓入缓出曲线移动到下一张。相同的手动翻页也使用连续缓动；拖动、滚轮、尺寸变化和页面隐藏会正确取消当前动画，首尾循环仍连续。
- 展台增加细线双框、登记刻线、照片序号和文案侧线；降低邻片与当前片的视觉跳变，保持完整比例主图、紧凑照片带及作者真实文案。
- 全屏回放改为 900ms 双层交叉淡化，再完整停留 4 秒。新图解码完成前保留已经加载的上一帧，快速切换时隔离过期回调；保持暂停、重试、键盘和完整照片内容，减少动态模式不做过渡。

## 实际验收

- 1440×1000 桌面：检查照片展台、日常卡片、四主题登录封面及其边缘动效、全屏照片回放。登录两栏实际测得约 597px / 760px，符合 44:56。
- 390×844 手机：检查照片展台、等高卡片、回放、注册表单上下部及全局控制按钮。卡片高度均为 246px，回影被隐藏；全景开关可以关闭，跨页面保留状态。
- 1024×800 注册补查两栏约 408px / 541px；320×740 登录和 1886×1008 四列卡片补查通过，无横向溢出。宽屏卡片均为 400px。
- 主相册采样观测到约 4 秒静止停留、约 1.1 秒连续缓动及末张回首张。回放实测同时存在两张已解码画面，透明度连续交替，约 900ms 后退场层清理。
- 浏览器错误/警告为 0。截图及计时、尺寸数据保存在本机忽略目录 `data/quiet-atmosphere-2026-11-17/`。
