# 2026-11-17 首页构图与照片节奏

本次完整发布使用 `feat/composed-home-layout`，以此前线上版本 `4ff1478`（PR #5）为基线。实现、修复、验证与说明均在同一分支提交。

## 相对上一版的优化

- **登录后首页重新约束排版。** 上一版自然高度分栏会被竖图拉成长列，照片之间出现不规则空洞。现在首页、日常卡片及照片墙使用按行对齐的响应式网格，卡片底部信息对齐，正文摘要限定行数。桌面首页三列，中等屏幕及手机两列，窄手机单列。
- **竖图完整显示，同时控制尺寸。** 缩略图展示区桌面最高 228px、手机最高 178px；照片本身保持比例，边缘紧贴图片，外侧为主题纸面。照片不会撑成长条；点击后仍可放大完整查看。视频封面共用这一规则，无封面视频保留可点击占位。
- **相册按实际照片宽度排布。** 照片共享底部基线，高度上限为桌面 210px、手机 182px；横竖照片之间的距离按真实相纸宽度计算，替换旧的固定间距。轮播区域桌面缩至 340px，手机 286px；减少装饰侵占，保留滑动、拖拽、方向键、刻度及详情入口。非常狭长的照片使用自适应重叠量，避免相纸顺序倒置；混合宽度的手机叠放连续插值，三张照片循环时先淡出再换边，避免中途跳动。
- **右下角交互有明确反馈。** 按钮展开前景小景面板，四主题分别呈现叶影、纸船潮汐、胶片转轮、星月流光，可重播、关闭、点击外部关闭或按 Esc 关闭。背景线稿减淡，移除巨大的英文装饰字，减少视觉干扰；系统要求减少动态时显示静态小景。
- **重新绘制无标签的小角色。** 移除相册右下角旧角色及“记忆保管员”说明，新纸质小灵出现在欢迎语、小景入口、明信片边角及空状态，按主题调整细节配色。体积受限，不挤占照片的位置。
- **文案统一为纸笺与旧光的语气。** 调整首页、明信片、日常目录、空状态及回放结束语；保留功能按钮的清楚含义和无障碍标签。首页主句“死亡不是终点，遗忘才是。”保留，回放间隔继续为 2.5 秒。
