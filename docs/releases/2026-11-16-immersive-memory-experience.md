# 2026-11-16 竖图、明信片与沉浸式日常

本次完整上线统一使用 `feat/immersive-memory-experience`，对比基线为上一版线上提交 `d1b2d52`。功能、样式、修复和发布说明在同一分支多次提交。

## 相对上一版的优化

### 竖图从衬底适配改为相纸适配

上一版保留固定横向画框，仅将图片设为 contain，竖图左右仍有很宽的留白。本次让首页、日常列表、照片墙和详情中的图片按实际比例撑开画框，列表采用自然高度分栏，时光相册的竖图相纸随照片变窄。完整保留画面，既不裁切也不拉伸。

媒体 API 返回已有的宽高信息，为图片预留正确比例；旧记录可通过图片自然尺寸适配。修复历史绝对定位对新图片高度的影响，保留无封面视频与加载失败时的可操作占位。

### 明信片成为可使用的工作台

- 填写收件人、正文、署名，选择主题插画或最近照片作为封面。
- 写信灵感、自动翻面、信封展开、完整正文滚动预览。
- 草稿按账号保存在当前浏览器，存储不可用时明确提示。
- 导出同时包含照片封面和完整信件的 PNG；照片等比例显示，超出可容纳行数会提示，不静默截断。
- 保存为私密文字日常，并可打开已保存的记录。照片封面用于预览及下载，不会重复关联已有附件。

### 我的日常真正跟随主题

四种主题扩展到档案封面、统计、筛选、搜索、卡片、时间线、照片墙与空状态：植物手账、潮汐来信、胶片档案、月夜观测。新增当前已加载记录的真实目录，可展开/收起、切换浏览方式、定位或打开记录；原有筛选、分页和管理操作保留。

### 更明显、可操作的动效

首页及日常页增加滚动入场、卡片透视与光照、阅读进度及分层背景视差；主题风景按钮可分别唤起叶片、潮汐、胶片或星空。图片尺寸不受动效改变，内容在动画脚本加载失败时仍直接可见；触屏不启用鼠标倾斜，系统减少动态设置下取消动画。

用户指定的参考站 `motionsite.ai` 未能通过网页读取和浏览器权限检查，未声称实际查看其交互。本次采用滚动编排、纸张层次和可操作的主题场景实现上述交互。
