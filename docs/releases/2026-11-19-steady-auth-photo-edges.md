# 稳定的账号入口与四周照片虚影

本次补充发布以上线的 PR #18（`5c58219`）为基线。之前的手机顶栏、管理台与封面手势已随 PR #18 发布。

## 相对上一版

- 登录与注册共享同一块外框及短片。切换时保留卡片位置、画面和播放状态，表单按对应模式更新。直接访问、刷新和浏览器前进后退均使用原有入口。
- 首页的照片墙按屏幕宽度预留 7–14 像素边距，并把原图色彩柔化延伸到上下左右。横图、竖图和方图保留完整内容。
- 加强五套实拍封面的运动。森林薄雾沿林梢横移、冰山水面产生波纹、草坡出现掠过的风纹、裂谷沿河床拂过薄尘、海洋持续涌动。我的日常和发现日常的横幅都使用当前主题摄影，日常列表保留用户的照片。

## 验收与发布

- 桌面首页和手机发现页逐套对比了连续帧。照片墙验收了横图和竖图的四周留边及完整比例。
- 登录注册在 320、390、1440 像素下反复切换，核对了外框、插画和标签的尺寸与位置。分别测试了前进后退、播放不中断、表单验证、验证弹窗取消及第三方入口同时展示。
- 主题封面在设备不支持 WebGL 或系统开启减少动态效果时使用静态原图。生产部署由合并触发，结果见相应 GitHub Actions 运行。
