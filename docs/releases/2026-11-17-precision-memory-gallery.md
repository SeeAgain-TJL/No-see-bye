# 2026-11-17 等高日常与精密光学展台

发布分支：`feat/precision-memory-gallery`。对比上一版线上提交 `2e4a9e2`（PR #9）。本轮实现、视觉验收和发布说明均在同一分支分次提交。

## 相对上一版的变化

- 日常卡片从随正文长短变化的高度改为统一规格：桌面 400px，手机 246px。日期、预览、摘要、管理操作分区固定，长文留在详情页；整卡空白区与箭头可打开详情。大图、标题、标签、收藏、编辑、删除保持独立操作。横竖照片仍按原比例完整展示，不补写空缺的标题或正文。照片墙和时间线保留各自的浏览方式。
- 登录和注册撤掉卡通花朵、海景及月亮，改为四套原创矢量光学构成：纸白是机械光圈，海盐是折射棱镜，麦芽是叠层胶片，墨林是金属星轨。用实体边缘、刻度和材质分层建立视觉主体；点击开合、鼠标透视与连续运动互相配合。移除登录封面的光晕与指针泛光，手机使用独立的紧凑构图。
- 首页照片展台取消倾斜、缩放及邻片淡化，改为等高、窄间距的连续照片带，收紧上下留白并增加展台刻线与档案标识。当前照片保留完整画面，容器两侧只露出邻片作为继续翻阅的提示。
- 相册默认每 1 秒自动翻阅，支持连续首尾循环；减少动态模式不默认播放。照片解码前、悬停、后台和完整预览时暂停计时，手动操作停止轮播。首页照片回放也同步改为每张 1 秒，保持只显示真实照片。
- 全局风景从小物件漂浮改为四套几何运动：折纸风带、潮汐等高线与仪表、机械快门与胶片推进、星轨仪与硬边流星。右下角换为机械控制标记，触发整页场景；保留跨页状态，关闭后卸载动态图层，场景不拦截点击，减少动态和后台暂停仍生效。取消脉冲及指针径向泛光。
