# 加快首页照片呈现并调整桌面布局

以上一线上版本 PR #27 为基线。

- 访客照片请求与会话检查并行启动；首页前四张高优先级加载，其余预览延迟加载。访客封面视频让照片预览先行，故事和明信片功能改为按需加载。
- 首页照片维持原始长宽比，桌面排列为每行四张，窄屏保留两列。「查看照片」入口优化为紧凑的触控友好按钮。
- 扩大并居中登录注册表单区域，降低宽屏布局的两侧留白，同时保持模式切换时主要表单字段与插画稳定。

生产构建、lint、类型、布局和 459 项 API 集成检查通过。Chromium 回归覆盖访客与登录状态、优先加载、图片原比例、桌面四列、移动双列、照片预览、相册入口和账号切换；登录注册布局验证 1920 至 320 像素宽度，以及社交登录按钮有无两种状态。

加载验收使用本地照片夹具，不代表公网耗时。旧照片首次生成缩略图以及弱网仍可能延迟显示。本次无数据库迁移或 Nginx 配置变更；部署状态以合并提交对应的 GitHub Actions `Deploy production` 为准。
