# 日常相册、账号入口与回收站 · 2026-11-22

基线：上一线上版本 `3f4a315`（PR #23）。本次沿用一条发布分支，不更换主题素材、不迁移数据库、不更改登录鉴权、证书或服务端口。

## 用户可见变化
- 登录、注册只显示一组有当前状态的页签。桌面卡片最大 900px，输入区最大 358px；手机保持 44px 以上的操作区域。主题插画静态展示，不加载播放器，也不叠文案。
- 我的日常（含未登录入口）与发现日常共享紧凑页头：16:9 完整风景图、栏目标题和导航、独立操作区。不使用旧版内框、遮罩和封面视差。按月、随机浏览、封面放大保留；手机主要操作另起一行。
- 我的日常和发现日常的照片网格统一为 4:5 相框、原比例前景和同图虚化底。收藏、编辑、移到回收站有文字及独立触摸区域。图片预览点击关闭，仍支持滚轮、双指缩放、滑动翻页和 Esc；视频保留独立关闭按钮。
- 手机顶部搜索占用剩余宽度；设置首屏可进入回收站。回收站支持单条确认永久删除、恢复和原有批量清空。单条操作限定本人、记录 ID 和入站时间，仅清理选中记录及其附件；文件系统故障可重试。精简密码设置与列表装饰文案。

## 验证与上线
- 本地生产构建，以及 1920、1280、768、390、320px 的登录注册、两处页头、照片比例、关闭预览和按月交互验证通过。脚本：`scripts/test-journal-masthead.mjs`。上一轮本地夹具验证过手机设置到回收站的单条删除，未操作生产记录。
- 以此 PR 合并提交的 Linux deployment bundle 为正式发布记录；构建、隔离归档测试、生产部署和独立公网检查完成后再确认上线。没有在生产环境测试注册新用户或删除数据。
