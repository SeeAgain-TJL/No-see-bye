# 动态封面、手机顶栏与主题管理台

本次发布以上一版 PR #17（`9a9eb86`）为基线。分支 `feat/living-covers-mobile` 集中交付这一轮修复。

## 相对上一版

- 手机顶栏把退出登录放在头像右侧，搜索、主题、头像和退出保留足够的触控面积。快捷搜索聚焦时只有一道圆角描边。窄屏相册欢迎标题保持单行。
- 登录与注册的画面和表单在桌面视口垂直居中，移除插画里的白色取景框。五个短片按钮点击后立即显示主题反馈与播放进度，场景分别出现萤火、冰光、飞信、升灯和水纹。
- 首页和日常的主题摄影接入实时动效。海洋画面里的浪花纹理持续流动，冰山水面、森林薄雾、草坡风纹和裂谷光线也各有运动。移除封面的放大按钮，桌面双击、手机连点两下、键盘 Enter 都可以打开原图。查看器支持双指、滚轮、键盘和加减按钮缩放。电影语录只显示片名。
- 管理台将指标、粒子场、站点状态和新增明细重新分区。五个主题具有各自的粒子形态、运动和配色。30 天活动可与新增趋势联动，查看当天注册用户和日常作者。

## 验收与发布

- 用 Chrome 检查 320、390、1440 和 1635 像素视口，验证手机顶栏退出、搜索描边、登录垂直位置、五套短片反馈、首页与日常封面及管理台布局。在 Pixel 9 触摸模拟验证了两次轻点打开照片和放大。
- 五套主题摄影和管理台粒子视图均成功渲染。对比海洋首屏连续画面，确认浪花帧变化。使用隔离管理员核对了 30 天数据、日期联动、拖动和复位。
- 主题摄影和管理台粒子视图使用 WebGL。浏览器关闭 WebGL 或系统开启减少动态效果时，主题摄影保持静态照片。生产部署通过合并至 `master` 触发，结果记录在 GitHub Actions。
