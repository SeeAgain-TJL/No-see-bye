# 2026-11-17 卷册、展页与整页风景

发布分支：`feat/editorial-memory-world`。对比上一版线上提交 `8fd833c`（PR #6）。本次重构与审查修复均在同一分支分次提交。

## 相对上一版

- 登录/注册从居中的小卡片改为近全视口的分栏画布，压缩外围空白；主题序言、插画与表单构成完整页面。手机采用紧凑封面与完整表单，保留登录、OAuth、验证码及错误处理。
- 修正个人入口在访客状态下自动切为公开数据的行为。`/memories` 现在是独立的私人卷册入口，未登录展示锁定书页；`scope=public` 才展示发现日常。
- 我的日常使用装订卷册、真实月份索引、珍藏入口和篇章目录；发现日常使用开放版头、罗盘、真实标签/地点路径、随机公开记录与作者信息。文案统一为文学与哲学语气，操作与删除提示保留准确含义。
- 首页不再并列三张尺寸悬殊的相纸。改为单幅主画面、日期与正文侧栏、等规格缩略片索引，默认选取第一条可展示的影像。保留完整原图、放大、横向手势、方向键及详情入口；近期记录改为紧凑的阅读条目。
- 照片墙按原图比例分配宽度，同一行保持等高，整行共同占满可用宽度。边界情况下限制高度并居中，避免孤立竖图拉成巨幅；极窄竖图可增加同行数量。删除旧的相纸弹簧轮播及其测试，替换为当前照片墙布局检查。
- 右下角的局部弹框彻底移除。开关直接控制全页叶影、潮汐纸船、胶片扫光或星河轨迹；状态在当前浏览器标签页跨页面保留。背景只保留轻量边缘纹理，避免大圆线覆盖版面。导航、筛选、输入、按钮、卡片及滚动入场都有对应反馈，覆盖登录前后及其他页面；触屏、减少动态与后台暂停各自处理。
