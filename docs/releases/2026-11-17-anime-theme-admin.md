# 主题动漫场景与管理台

基线：上一次线上版本 `21cfa7ebc2111472946fb70752315382a42b856e`（PR #11）。

本次完整上线使用一个分支 `feat/anime-theme-admin`，过程提交与最终上线均沿用该分支。

## 相对上一版

- 登录与注册左侧由机械光学装置改为原创分层动漫风景：纸白温室、海盐站台、麦芽夕照街景、墨林月下森林。前中后景随鼠标产生视差，点击或触摸触发各自的风叶、飞信、电车显影与星河变奏。保留桌面 44:56 比例与手机紧凑排版。
- 修复右下角动效被窄遮罩裁掉、登录表单遮住的问题。四主题各有蝴蝶、鱼群、燕影、月蛾，开启即有明确的全页飞行响应，随后保留自然的场景运动；关闭移除，跨页面保持当前状态，后台页面暂停，减少动态偏好提供静态反馈。
- 四主题重新调整纸面、墨色和辅助文字对比度，并增加各自的草木纸纹、海潮曲线、胶片边缘、夜林星点等材料细节；不改变照片本身颜色。
- 新增 `/admin`，管理员登录后直接进入管理台。包含总用户、七日活跃、记录/媒体/存储概况、北京时间每日趋势，以及用户搜索、分页与每位用户的用量、登录次数和最近活跃数据。手机版以紧凑信息卡排列。
- 管理权限在每次请求时读取数据库校验，后台只返回使用元数据，不返回私密正文、媒体内容或密码哈希。登录与活跃追踪从本次上线开始，不伪造历史数据。
- 管理员通过独立幂等脚本创建，密码从运行环境传入，不写入仓库或发布包。已存在同名普通用户、联系邮箱冲突时拒绝创建，已有管理员不会被初始化脚本重置。
- 根据用户后续选择，暂不启用邮箱验证：`PASSWORD_EMAIL_VERIFICATION=false` 为默认值。修改密码仍要求正确的当前密码，更新时撤销其他会话。主、备用邮箱只作联系地址，未标记为已验证。未来可显式开启已实现的 SMTP 验证流程。

## 验证

- 全局 TypeScript、ESLint 与正式 webpack 构建通过。
- `npm run test:layout`：243 组横竖照片排布，以及照片筛选、顺序、去重与原始内容保留检查通过。
- `npm run test:security`：51 项管理/密码安全 API 检查通过，另验证初始化幂等、拒绝普通账号提权、邮箱冲突及验证码并发单次消费。
- `npm run test:integration`：399 项 API 检查通过。验证码测试只使用本机隔离 SMTP 收件箱，没有向外部邮箱发信。
- 动漫 SVG 已单独渲染审查构图。这只是素材审查，不替代网页视觉或交互验收。

## 验收限制

本次 Windows 浏览器工具因无法可靠识别当前网址而主动停止；本地预览启动随后被自动审批规则拒绝（`blocked by policy`）。未改端口、换工具或绕过拦截。因此本轮没有完成新版桌面/手机网页的浏览器视觉验收，不将源代码审查或 SVG 素材渲染记为视觉验收通过。

正式发布结果、PR 和部署检查将在合并后的 PR 说明中记录。部署后通过服务器本机接口核验真实管理员登录、管理权限和统计返回；不在生产修改用户已有记录或密码。
