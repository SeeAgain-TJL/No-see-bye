# 2026-11-16 四主题与照片体验精修

本次完整上线使用 `feat/theme-gallery-refinement`，对比基线是上一版线上提交 `87ea623`。按钮、主题、媒体和性能改动使用同一分支多次提交。

## 相对上一版的优化

- **按钮和排版**：统一按钮尺寸、圆角、阴影、按压和键盘焦点；重新协调标题、正文、日期及卡片留白；分类改为清晰的分段选择器。
- **主题专属设计**：纸白为植物标本、方格手账和布纹胶带；海盐为贝壳、水纹和半透明边框；麦芽为胶片齿孔、打字机日期和旧档案印记；墨林为月亮、星座、萤火与夜景插画。主题菜单显示各自材质的小样，并支持矮屏滚动。
- **完整长图**：首页卡片、时光相册、日常列表、照片墙和详情中的照片按比例完整放入画框；移除会再次裁切图片的悬停放大。留白以主题衬纸填充，原图不拉伸。
- **播放节奏**：照片和文字画面从 5 秒缩短到 2.5 秒；照片完成加载后才开始计时。视频仍播放到结束再继续，保留暂停、方向键和系统减少动态支持。
- **加载体验**：正常切图不再生成新的重试 URL，复用缓存；单张图片替代双图片背景，当前画面优先、下一张低优先预取，节省流量模式和弱网络下不预取。全屏先显示已有预览，再切换高清画面。
- **首次高清生成**：限制原图读取与解码的总并发，避免等待队列同时保留多份大原图；复用已取得的文件大小，减少重复访问；在维持 1920px 与质量 82 的前提下减少 WebP 编码搜索耗时。原始文件不变。
