## 本次行为

- 沿用既有星图的点选、预览和详情入口，放入登录后的首页 Hero。星图只展示最近一页（最多 12 条），明确标注范围；时间按先后排列、颜色对应心情、大小对应附件数。
- 保留 Daydream 原有场景切换、暂停和减少动态效果支持，通过“心情明信片”切换进入。
- 首页“播放回忆”打开原生模态对话框，支持最近、本月、往年今日、随机；每次最多 30 条记录，每个附件是一个画面，无附件记录以文字展示。
- 图片解码完成后才启动 5 秒计时；支持暂停、上一段/下一段、方向键、空格、触屏滑动、Esc、关闭后的焦点恢复。图片与视频使用完整画面显示；视频默认静音并提供声音开关，结束后继续下一段。系统减少动态效果时关闭缩放且初始暂停。媒体失败等待重试或手动切换。
- 年历替换月历侧栏，展示所选年全部 365/366 天；月份与日期按上海时区计算。点选显示当天记录数与心情，再通过“查看这一天”进入已有日期筛选。
- 当日多条心情取出现最多的一种，票数相同取较近记录。未设置心情的记录使用独立样式。连续天数按不同记录日计算，允许今天尚未记录时延续到昨天，并注明统计截止日。
- 全年统计与随机播放查询完整个人档案，不从首页 12 条推断；接口校验用户与软删除状态，不改数据库结构。

1. `npm run lint`、`npm run check`、`npm run build -- --webpack`。
2. `scripts/integration.mjs` 在隔离数据库验证权限、分页范围、随机抽样、心情票数、闰日、上海日期边界、连续记录、删除后排除与无效参数，以及既有认证/上传/配额功能。
3. Chromium 桌面与手机上下文操作真实隔离账号及上传附件，覆盖完整照片、定时播放、暂停、键盘、触屏、四种范围、结束重播、日期筛选、主题、减少动态效果、媒体失败重试与视频播放。
4. Linux 使用精确提交构建安装包，对该安装包运行有限配额和无限配额集成测试，再备份、发布、重启、核对线上资源与健康状态。
